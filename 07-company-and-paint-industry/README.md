## Paint basics every sales admin should know
| Term | Meaning |
|---|---|
| Putty | Smooth base layer that fills wall imperfections |
| Primer | First coat; improves adhesion and sealing |
| Emulsion | Water-based wall paint (interior/exterior) |
| Enamel | Oil/solvent-type gloss paint for wood and metal |
| Distemper | Low-cost, water-based wall finish |
| Tinting machine | Mixes colourants into a base to create thousands of shades |
| Base / shade | Base paint + colourant = final colour |
| Coverage | Area per litre (varies by product — check the label) |
| Sheen | Matt / soft sheen / gloss |
| Decorative vs Industrial vs Auto | Homes & buildings vs factory/metal vs vehicles |
