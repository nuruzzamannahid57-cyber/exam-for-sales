# 06 · Solutions
1. Enterprise Resource Planning — integrates departments on one data set, removing duplicate entry and giving real-time visibility.
2. Master / transaction / master / transaction.
3. Sales Order → Delivery → Goods Issue → Billing.
4. VA01 = create sales order · VL01N = create delivery · VF01 = create invoice · MMBE = stock overview.
5. Authorised credit controller / finance (per company policy), typically via the credit-release function (e.g. VKM1); the block shows on the order's status.
6. First check the order's pricing condition; if the same wrong price recurs, fix the master-data condition record (otherwise every future order repeats the error).
7. 1 order → 2 deliveries (80, 20) → 2 invoices (typically one per delivery, depending on setup).
8. Sales order → delivery document → goods-issue/POD → invoice.
