# 02 · Order-to-Cash & Dealer Admin 🔄

**Why it matters:** this *is* the Sales Admin job. Master the flow and the documents.

## The cycle (memorise this)
```
Dealer order → Sales Order (SO) → Credit check → Stock check
→ Delivery / Challan → Dispatch → Invoice → Dealer receives goods (POD)
→ Payment collection → Reconciliation → Claims / Credit notes
```

## Key documents
| Document | What it is |
|---|---|
| Sales Order (SO) | Internal record of what the dealer ordered |
| Delivery Order / Challan | Authorises and lists goods leaving the warehouse |
| Invoice | Bill: quantity × price − discount (+ VAT) |
| POD (proof of delivery) | Signed receipt that goods arrived |
| Credit Note | Reduces what the dealer owes (returns, price correction, claims) |
| Debit Note | Increases what the dealer owes (undercharge) |
| Statement of Account | Dealer's invoices, payments and balance |

## Concepts
- **Credit limit:** max outstanding a dealer may carry. New order + outstanding > limit → order is **held** for approval.
- **Credit days / terms:** e.g. 30 days. Due date = invoice date + credit days.
- **Overdue:** days past due date. **Aging buckets:** 0–30, 31–60, 61–90, 90+.
- **Discount types:** trade discount (on invoice), cash/early-payment discount, volume rebate, scheme/claim.
- **VAT:** standard rate in Bangladesh is 15% (confirm the current rule with NBR).
- **Reconciliation:** matching your ledger with the dealer's records and bank deposits.

## Admin habits that win interviews
Double-check master data (price, discount, dealer code) · keep an audit trail · flag exceptions early · follow up on collections politely but firmly · never release a blocked order without approval.
