# 03 · Sales Reporting & KPIs 📊

## Formulas to know cold
| KPI | Formula |
|---|---|
| Achievement % | Actual ÷ Target × 100 |
| Growth % (YoY / MoM) | (Current − Previous) ÷ Previous × 100 |
| Contribution % | Part ÷ Total × 100 |
| Run rate | Sales so far ÷ days passed |
| Required run rate | (Target − sales so far) ÷ days remaining |
| Projected month-end | Run rate × total days |
| Collection efficiency % | Collected ÷ Due for collection × 100 |
| Fill rate % | Qty delivered ÷ Qty ordered × 100 |
| Average order value | Total sales ÷ number of orders |
| Gross margin % | (Revenue − COGS) ÷ Revenue × 100 |

## Vocabulary
**Primary sales** = company → distributor/dealer. **Secondary sales** = dealer → retailer/customer. **MTD / QTD / YTD** = month / quarter / year to date. **Backorder** = ordered but not yet available. **SKU** = one unique product item. **Pareto (80/20)** = a few dealers/products give most revenue.

## Good report habits
One-line headline first ("Sales 86% of target, Rajshahi lagging") · same format every period · compare to target AND last period · always list top 3 risks + next actions.
